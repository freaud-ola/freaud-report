## 二、核心玩法

### 2.1 游戏元素

| 元素 | 说明 |
|------|------|
| 牌堆区 | 多层叠放的图案牌，类似麻将牌俯视视角 |
| 槽位区 | 底部 7 格区域，存放已点击的牌 |
| 图案牌 | 共 N 种图案（默认 12 种），每种出现次数为 3 的整数倍 |
| 层叠关系 | 上层牌覆盖下层相邻 4 张牌；被覆盖的牌处于"锁定"状态 |

### 2.2 操作规则

1. **点击牌**：只能点击未被任何上层牌遮挡的"自由牌"
2. **进入槽位**：被点击的牌进入槽位区，同类型的牌自动聚合相邻
3. **自动消除**：槽位区中 3 张连续相同图案的牌自动消除，计为 1 组
4. **连消机制**：消除后剩余牌向左聚拢，可能触发新的连续消除
5. **不可点击**：被至少一张上层牌覆盖（重叠面积超过阈值）的牌显示为灰暗状态，无法点击

### 2.3 牌的可达性判定

```
tile_A（下层）被 tile_B（上层，z = tile_A.z + 1）遮挡的条件：
  X 方向重叠 > MIN_OVERLAP  AND  Y 方向重叠 > MIN_OVERLAP

其中 MIN_OVERLAP 推荐值 = 10px（约牌宽的 15%）
```

### 2.4 层级结构（标准关卡示例）

```
层级 z=3 ：  1 张（居中）
层级 z=2 ：  3×3 = 9 张（偏移半格）
层级 z=1 ：  5×5 = 25 张（偏移半格）
层级 z=0 ：  7×7 = 49 张（底层铺满）
─────────────────────────
合计       84 张（= 28 组 × 3 张）
```

每相邻两层偏移半个格距（tile 宽度的一半），使上层每张牌恰好覆盖下层 2×2 共 4 张牌的交界处。

## 三、胜负判定

| 判定 | 条件 |
|------|------|
| **胜利** | 牌堆区所有牌全部消除，且槽位区同时清空 |
| **失败** | 槽位区已满 7 张，且不存在 3 张连续相同图案可消除 |

## 五、道具系统

| 道具 | 图标 | 功能 | 默认次数 | 触发条件 |
|------|------|------|---------|---------|
| 撤回 | ↩️ | 将槽位区中最近一次放入的牌退回牌堆，恢复至点击前状态 | 3 次 | 槽位区非空 |
| 洗牌 | 🔀 | 随机重新分配牌堆区所有剩余牌的图案（总数和每种数量不变）| 2 次 | 任意时刻 |
| 移出 | 📤 | 将槽位区末位牌移至暂存区，腾出 1 个槽位格子 | 2 次 | 槽位区非空 |

- 次数耗尽后按钮变灰禁用
- 扩展：分享/看广告可补充道具次数

## 六、视觉与动效规范

### 6.1 牌的状态样式

| 状态 | 样式描述 |
|------|---------|
| 正常（可点击）| 白色圆角卡片，底部阴影体现层次感，悬停时上浮 3px |
| 锁定（被遮挡）| 灰暗色（亮度 65%，饱和度 50%），pointer-events: none |
| 点击瞬间 | 缩放弹出动画（scale 1→1.15→0），0.25s |
| 消除瞬间 | 槽位格闪黄后缩放消失（scale 1→1.2→0），0.35s |

### 6.2 层次感表现

- 通过 `box-shadow` 的右下偏移模拟牌的物理厚度
- 层级越高，阴影偏移越大（每层 +3px）
- CSS z-index 按 z 层级设置，确保上层牌永远显示在上方

### 6.3 结局动效

- **胜利**：全屏庆祝弹窗，烟花/撒花效果，展示步数和消除组数
- **失败**：弹窗提示，支持"再来一局"重置

## 七、关卡设计

### 第一关：引导关（极简）

| 属性 | 值 |
|------|---|
| 牌数量 | 18 张（6 种图案 × 3 张）|
| 层数 | 1 层，全部牌可直接点击 |
| 通关率 | ≈ 100% |
| 设计目标 | 让玩家在 30 秒内必然通关，建立游戏认知，形成"我很厉害"的错觉 |

### 第二关：挑战关（极难）

| 属性 | 值 |
|------|---|
| 牌数量 | 84 张（12 种图案，每种 6–9 张）|
| 层数 | 4 层 |
| 通关率 | < 5%（设计上接近不可能） |
| 随机性 | 每局图案重新随机分配，可重玩 |
| 设计目标 | 用极低通关率制造话题，驱动截图分享和邀请好友 |

## 八、社交传播机制

1. **结果卡分享**：每局结束后弹出成绩卡（含当日全服通关率），可一键分享至微信群/朋友圈
2. **助力机制**：失败后展示"邀请好友助力"入口，邀请成功后获得额外道具次数
3. **排行榜**：好友中谁先通过第二关，展示好友排行
4. **每日挑战**：每天关卡布局随机重置，驱动日活

## 九、核心算法说明

| 算法 | 说明 | 复杂度 |
|------|------|--------|
| 可达性判定 | 矩形重叠检测，遍历上一层所有牌 | O(n) |
| 槽位插入 | 从末尾向前查找同类型牌的最后位置 | O(k)，k 为槽位数 |
| 消除检测 | 线性扫描槽位区，找 3 连同类 | O(k) |
| 洗牌算法 | Fisher-Yates 均匀随机打乱 | O(n) |
| 撤回快照 | 保存操作前牌状态快照（数组序列化）| O(n) |
